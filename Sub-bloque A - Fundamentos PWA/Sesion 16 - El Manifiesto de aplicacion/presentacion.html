SECCIÓN 01

¿Qué es el manifest.json?

Un archivo JSON esencial para la integración de una PWA con el navegador y el sistema operativo.

DefiniciónPara qué sirve
¿Qué es el manifest? · 1.1

El archivo que define la app instalada

El manifiesto de aplicación es un archivo JSON esencial para la integración de una PWA con el navegador y el sistema operativo. Define su apariencia y su comportamiento una vez instalada en el dispositivo del usuario.

En una frase: sin manifest, el navegador no tiene forma de saber que tu web "quiere" comportarse como una aplicación instalable.

Es solo JSON

Un objeto plano de propiedades clave-valor. Ningún lenguaje nuevo que aprender.

Se enlaza desde el HTML

Una sola línea en el <head> conecta el manifest con tu página.

SECCIÓN 03

Los modos de display

La propiedad que más cambia cómo se siente la app instalada: cuatro niveles de inmersión.

fullscreenstandaloneminimal-uibrowser
Display · 3.1

De más a menos inmersivo

fullscreen

Toda la pantalla, sin ninguna interfaz del navegador ni del sistema. Casi exclusivo de juegos.

standalone

Se ve como app nativa: sin barra de direcciones. El modo más común — el nuestro.

minimal-ui

Como standalone, pero conserva controles mínimos de navegación (atrás/adelante).

browser

Pestaña normal del navegador. Comportamiento por defecto si se omite la propiedad.

Dato clave: si display se omite o vale "browser", la app no se ve como instalada aunque técnicamente lo esté.
SECCIÓN 04

Los íconos: tamaños y maskable

Dos tamaños obligatorios, y una propiedad que decide cómo se recortan en cada sistema.

192×192512×512maskable
Íconos · 4.1

Tamaños obligatorios y purpose

Cada objeto en icons trae src, sizes, type y opcionalmente purpose. Chrome exige, como mínimo, 192×192 y 512×512.

purposeQué significaCuándo usarlo
"any"El sistema puede recortarlo a cualquier forma, sin garantía de qué queda dentro.Íconos simples ya centrados.
"maskable"Tiene una zona segura central (~80%) pensada para recortarse sin perder contenido.Práctica recomendada hoy en día.

SECCIÓN 06

Caso real: el manifest del Gestor de tareas

Todo lo visto hoy, junto, en un solo archivo — y cómo verificarlo en DevTools.

manifest.json completo
Caso real · 6.1

El manifest.json completo

manifest.json
{
  "name": "Gestor de Tareas — Electiva PWA",
  "short_name": "Tareas",
  "start_url": "/index.html",
  "scope": "/",
  "display": "standalone",
  "theme_color": "#1A1A1A",
  "background_color": "#FFCC29",
  "icons": [
    { "src": "icons/icon-192.png", "sizes": "192x192", "purpose": "any" },
    { "src": "icons/icon-512-maskable.png", "sizes": "512x512", "purpose": "maskable" }
  ]
}
Caso real · 6.2

DevTools

Cierre

Resumen de la lección

  • El manifest.json le dice al navegador y al SO cómo debe verse y comportarse tu PWA instalada.
  • Propiedades clave: name/short_name, start_url, scope, display, theme_color/background_color, icons.
  • Los 4 modos de display: fullscreen, standalone (el más usado), minimal-ui, browser.
  • Íconos mínimos: 192×192 y 512×512; purpose: "maskable" para recortes seguros.
  • El manifest cubre 4 de 5 criterios de instalabilidad — el quinto llega con el Service Worker.
Cierre
